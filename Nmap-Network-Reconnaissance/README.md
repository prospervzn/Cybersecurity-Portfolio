# Nmap Network Reconnaissance

## Project Overview
This project documents my beginner-level network reconnaissance practice using Nmap in an authorised cybersecurity lab.

## Objective
To identify open ports and discover services running on a lab machine.

## Tools Used
- Kali Linux
- Nmap
- Metasploitable 2

## Lab Environment
Target: Metasploitable 2
Target IP: 192.168.236.131

## Activities
- Identified the target machine on the lab network.
- Scanned the target using Nmap.
- Identified open ports and running services.
- Reviewed the service versions reported by Nmap.

## Key Learning
I learned how network reconnaissance helps identify exposed services and provides information for further security assessment.

## Scope
All activities were performed in a controlled lab environment with an authorised target.
