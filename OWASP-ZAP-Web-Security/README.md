# OWASP ZAP Web Application Security Testing

## Project Overview
This project documents my introductory practice with OWASP ZAP, a web application security testing tool.

## Objective
To understand how OWASP ZAP can be used to inspect web traffic and identify potential web application security issues.

## Tools Used
- Kali Linux
- OWASP ZAP
- Web browser
- Burp Suite (for introductory comparison)

## Activities
- Started OWASP ZAP.
- Explored the Quick Start interface.
- Learned about configuring a browser to work through the ZAP proxy.
- Explored how web requests and responses can be inspected.
- Began learning about automated web application scanning.

## Key Learning
I learned the basic purpose of an intercepting proxy and how security testers use it to examine communication between a browser and a web application.

## Scope
Practical learning was conducted in a controlled environment. Further testing and documentation are ongoing.

## Important Note
This is an introductory learning project, not a claim of completing a full professional security assessment.
