# Linux and Kali Linux Cybersecurity Practice

## Project Overview
This project documents my practical learning of Linux commands and system navigation using Kali Linux.

## Objective
To develop basic Linux command-line skills needed for cybersecurity tasks.

## Tools Used
- Kali Linux
- Linux Terminal
- VMware

## Practical Activities
- Navigating directories using cd and ls.
- Creating and managing files and directories.
- Viewing file contents.
- Understanding file permissions.
- Using sudo for administrative tasks.
- Installing and managing software packages.
- Checking running processes and network services.

## Key Learning
I developed a better understanding of Linux command-line operations and how Linux is used in cybersecurity environments.

## Scope
All exercises were performed on my personal Kali Linux virtual machine.
